Tóm Tắt REST API Dành Cho Quản Trị Viên (ADMIN)

POST /api/v1/movies
Thêm mới bộ phim vào CSDL `movie_db`
PUT /api/v1/movies/{id}
Cập nhật thông tin chi tiết phim
POST /api/v1/showtimes
Tạo suất chiếu mới (chống trùng phòng)
PATCH /api/v1/seats/{id}
Khóa ghế hoặc đưa ghế vào bảo trì
GET /api/v1/tickets
Lấy toàn bộ danh sách vé trong hệ thống
POST /api/v1/tickets/{id}/cancel
Hủy vé với quyền quản trị viên cao cấp
